# Contributing / 参与开发

Keep changes focused and preserve native Goety models, animations, cooldowns and ownership rules. Use short responsibility-based names under `dev.flower.manualriding`. Comments explain intent and non-obvious restrictions, in Chinese followed by English.
修改应围绕具体问题，保留原生模型、动作、冷却和归属规则。类名简短明确，必要注释中文在前、英文在后。

Build the affected code and verify changed behavior. Changes to rendering or input need actual game checks. Include Minecraft, mod loader and Goety versions with reproduction steps and relevant logs in issue reports. Do not include credentials, private worlds or personal configuration.
构建修改过的代码，并验证受影响行为；渲染与输入变化需在游戏中检查。反馈时提供版本、复现步骤与相关日志。

Code contributions are under MIT. Observe the separate artwork terms and preserve third-party notices.
代码贡献采用 MIT，美术与第三方资源按相应条款处理。
